Current release

1.1.1 - 2026-08-29

Removes the obsolete pre-SLM2 native implementation from current source and makes the single-authority rule executable.

  • Deleted the former Rust CLI, v0 fixtures, tracked single-file model demo, and stale cross-checkout dependency.
  • Added a gate that rejects those retired surfaces and verifies the fail-closed canonical-source policy.
  • Kept the public SLM2 catalog and peer feed truthfully empty with no hosted model bytes.
  • Required any future native companion to start from the six-member SLM2 contract without fallback.

Replaces obsolete single-file catalog authority with the clean-slate six-member SLM2 catalog and explicit acquisition contract.
