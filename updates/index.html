1.1.2 - 2026-08-31

Prepares stricter direct-peer URL admission without claiming a deployment, live peer, qualified model, or public transfer.

  • Public peer URLs require HTTPS and HTTP is loopback-only.
  • Requires an exact root origin and rejects credentials, endpoint paths, query strings, fragments, and unsafe authority aliases.
  • Keeps the qualified composition catalog and current peer-announcement feed at exactly zero entries.
  • Records source preparation only; publication still requires a clean release commit, deployment, and exact public HTTPS readback.

  • Deleted the former Rust CLI, v0 fixtures, tracked single-file model demo, and stale cross-checkout dependency.
