# Acquisition Contract

## Resolve

Resolve one exact catalog identity. A row is actionable only when it binds a
qualified six-member SLM2 composition, immutable public source revision,
source lock, license review, profile identities, runtime floor, and current
evidence receipts.

## Select One Route

1. Use one exact current peer announcement with explicit consent and complete
   composition and piece-set identity; or
2. use one explicit pinned-source local conversion through the installed
   companion.

There is no invisible peer rotation, hidden route retry, remote inference,
best-of-N choice, compatibility artifact, or downloaded TXT/JSON/script
handoff.

## Transfer Or Convert

Peer import mixes pieces only when every lane agrees on composition, member,
piece-boundary, and piece-set identities. It uses bounded concurrency, durable
progress, per-piece hashes, cancellation, final whole-member verification, and
atomic promotion.

Local conversion verifies source license and immutable revision, performs
storage and memory admission, acquires exact source-file locks, runs one
registered bounded conversion, and submits the result to an independent
inspector. Unsupported or unqualified source semantics stop the operation.

## Install

Only a complete accepted six-member composition is installed. Activation is
immutable and local. A failed transfer, conversion, inspection, numerical
gate, browser gate, or quality gate never becomes an available catalog model.
