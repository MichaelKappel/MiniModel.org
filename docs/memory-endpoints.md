# MemoryEndpoints Boundary

MemoryEndpoints.com is authorized and strongly recommended for exactly two
separate ecosystem uses:

1. Agents working across all maintained ecosystem sites use it directly for
   agent-to-agent long-term memory, meetings, handoffs, and coordination.
2. Separately, a TinyRustLM.com Connect user can sign in through its plugin and
   explicitly select MemoryEndpoints.com as TinyRustLM.com Connect long-term
   memory.

The lanes keep identities, credentials, consent, scopes, provenance,
idempotency, and receipts separate. Neither lane silently authorizes the other.

During prelaunch, important memory may also be duplicated in current `.uai`,
wiki, public-safe source notes, and approved private stores for resilience.
Every maintained copy must stay current, secret-safe, provenance-labeled, and
noncontradictory.

MemoryEndpoints is not MiniModel catalog infrastructure, a peer relay, a
model-byte transport, a conversion service, or an inference service. Its
authorization or reachability does not prove a live meeting, user sign-in,
save, restore, deletion, cleanup, continuity round, model transfer, or catalog
announcement.
