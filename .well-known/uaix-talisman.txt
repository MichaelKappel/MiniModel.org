Purpose
MiniModel.org is a planned Rust-first peer-to-peer tiny model package catalog and exchange. This file is a public orientation export only.

Public Anchors
- Peer-to-peer or source-routed transfer, not hosted model-weight service.
- Signed or checksum-bound model manifests.
- Local verification before TinyRustLM import.
- Clear separation between catalog metadata, peer transfer, and local execution.
- Optional future MiniModel Peer Companion work remains user-run local software, not project-hosted byte infrastructure.

Public Boundaries
- MiniModel.org does not run model inference on its servers.
- MiniModel.org does not host runnable model weights.
- MiniModel.org does not claim ownership, endorsement, relicensing, or certification of third-party model weights.

Private Memory Boundary
The .uai directory is internal operational memory and should not be crawled or served as public documentation.

File Handoff Boundary
agent-file-handoff is an operational intake path, not a public content API.
