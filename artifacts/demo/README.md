# MiniModel Runtime Test Artifacts

This directory contains tiny deterministic `.slm` fixtures for local Rust, browser, and packaging tests. It is excluded from the MiniModel.org deployment manifest and the public site rejects every `.slm` route with HTTP 404.

TinyRustLM.com does not autoload this artifact. User models and peer pieces move only between consenting user-run peers or from a user-selected local file.
